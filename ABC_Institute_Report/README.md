# 📊 ABC Institute Power BI Dashboard  

## 📌 Project Overview  
This Power BI dashboard provides an interactive and data-driven visualization for **ABC Institute**, focusing on student and course details. The report highlights key insights such as revenue trends over the past **three years (2021-2023)**, revenue by **course location**, and revenue breakdown by **age group**.  

## 📈 Key Features  
- **Total Revenue Analysis (2021-2023):** Visual representation of revenue trends over the last three years.  
- **Course & Location Revenue:** Insights into the revenue generated from different course locations.  
- **Revenue by Age Group:** Breakdown of revenue based on student age demographics.  
- **Dynamic Filters & Interactivity:** Users can explore the data using interactive slicers for better insights.  

## 🛠️ Tech Stack  
- **Power BI** – Data visualization and dashboard development  
- **Data Source:** Excel
